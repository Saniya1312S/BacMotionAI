# 📊 Dataset Documentation

## Overview
The dataset contains **2,000 simulated bacterial trajectories** generated by the physics-based simulation engine.

## How to Generate
```bash
python scripts/generate_dataset.py
```
This creates `bacterial_motility_dataset.csv` in this directory.

## 14 Extracted Features

| Feature | Unit | Description |
|---------|------|-------------|
| `mean_speed` | µm/s | Average instantaneous speed |
| `std_speed` | µm/s | Speed standard deviation |
| `q25_speed` | µm/s | 25th percentile speed |
| `q75_speed` | µm/s | 75th percentile speed |
| `cv_speed` | — | Coefficient of variation (std/mean) |
| `speed_skewness` | — | Speed distribution skewness |
| `speed_kurtosis` | — | Speed distribution excess kurtosis |
| `mean_alignment` | — | Mean |cos(θ)| wall alignment [0,1] |
| `std_alignment` | — | Alignment variability |
| `wall_rate` | — | Wall collision frequency per step |
| `near_wall_frac` | — | Fraction of time within 15% of wall |
| `mean_run_len` | steps | Average run length between tumbles |
| `confinement_idx` | — | Cell radius / channel width |
| `eff_diffusivity` | µm²/s | Effective diffusivity v²/(2Dᵣ) |

## 5 Target Classes (Regimes)
| Regime | Description |
|--------|-------------|
| Inhibited | Low speed, erratic motion (antibiotic-like) |
| Wall-Guided | High wall accumulation and alignment |
| Chemotactic | Long directed runs, low variability |
| Confined | Frequent wall collisions, short runs |
| Free-Swimming | Open exploration, moderate speed |

Regimes are assigned from **measured behavior**, not input parameters — preventing data leakage.
